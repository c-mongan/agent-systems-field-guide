# Decision matrix

| Need | Primitive | Key boundary |
|---|---|---|
| universal rule | instructions | applies to most tasks |
| reusable expert method | skill | model chooses how |
| conditional detail | reference | loaded only when needed |
| exact result | script/tool | deterministic contract |
| remote shared capability | MCP | protocol and trust boundary |
| event reaction | hook | runs without model discretion |
| fixed path and side effects | workflow | state and order controlled |
| independent context | subagent | large separate reasoning task |
| durable responsibility | specialist agent | distinct tools or authority |

When two rows fit, choose the lower-cost primitive and prove it with an eval.
