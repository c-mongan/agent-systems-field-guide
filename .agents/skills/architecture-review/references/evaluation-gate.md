# Evaluation gate

Before changing architecture:

1. freeze representative case IDs;
2. save the baseline configuration and trace;
3. state the target metric and acceptable regressions;
4. change one boundary;
5. rerun the same model, tools, data, and grader;
6. compare paired results;
7. expand the case set with new failures;
8. keep the change only when the benefit pays for cost and risk.

Never use generated structural lab numbers as a substitute for live production evidence.
